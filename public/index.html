🚀 Como Subir a Aplicação (Cloud ou Local)

Esta aplicação já está rodando ao vivo aqui no painel! Para hospedar na nuvem gratuitamente ou rodar junto com seu container PostgreSQL:

1. Subir Front-end Grátis (Vercel / Netlify / GitHub Pages):

Basta arrastar a pasta com este arquivo index.html para app.netlify.com/drop ou vercel.com. Fica online em 10 segundos com HTTPS.

2. Subir PostgreSQL + API via Docker Compose:

Copie os arquivos docker-compose.yml e schema.sql abaixo e rode docker compose up -d.

📄 docker-compose.yml (PostgreSQL 16 + Adminer) 
version: '3.8'
services:
  postgres:
    image: postgres:16-alpine
    container_name: cyberfinance_pg
    restart: always
    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: cyberpassword2026
      POSTGRES_DB: cyberfinance
    ports:
      - "5432:5432"
    volumes:
      - pgdata:/var/lib/postgresql/data
      - ./schema.sql:/docker-entrypoint-initdb.d/schema.sql

volumes:
  pgdata:
📄 schema.sql (DDL Completo PostgreSQL) 
CREATE TABLE IF NOT EXISTS fin_lancamentos (
  id BIGINT NOT NULL,
  mes_ref VARCHAR(3) NOT NULL,
  descricao VARCHAR(255) NOT NULL,
  categoria VARCHAR(100) NOT NULL,
  tipo VARCHAR(20) NOT NULL,
  valor NUMERIC(14,2) NOT NULL DEFAULT 0,
  data_vencimento DATE NOT NULL,
  status VARCHAR(20) NOT NULL,
  cartao_unificado VARCHAR(100),
  PRIMARY KEY (mes_ref, id)
);

CREATE TABLE IF NOT EXISTS fin_cartoes_compras (
  id BIGINT NOT NULL,
  mes_ref VARCHAR(3) NOT NULL,
  cartao VARCHAR(100) NOT NULL,
  item VARCHAR(255) NOT NULL,
  categoria VARCHAR(100) NOT NULL,
  valor_parcela NUMERIC(14,2) NOT NULL,
  parcela_atual INT NOT NULL DEFAULT 1,
  total_parcelas INT NOT NULL DEFAULT 1,
  parcelas_faltantes INT GENERATED ALWAYS AS (GREATEST(0, total_parcelas - parcela_atual)) STORED,
  saldo_futuro NUMERIC(14,2) GENERATED ALWAYS AS (GREATEST(0, total_parcelas - parcela_atual) * valor_parcela) STORED,
  PRIMARY KEY (mes_ref, id)
);

🗓️ Ciclo Financeiro

O ciclo de um mês começa no dia de virada do mês anterior e termina na véspera do dia de virada do próprio mês. Com virada no dia 15, o ciclo de Novembro vai de 15/10 a 14/11.
